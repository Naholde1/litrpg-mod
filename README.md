# LitRPG: Система — мод для Minecraft 1.20.1 (Forge)

Мод в духе литРПГ: уровни, опыт, характеристики, мана и навыки, уровни мобов,
кастомные мобы и боссы, отдельное измерение «Изнанка», мини-карта и карта мира.

## Установка (TLauncher)
1. В TLauncher выбери версию **Forge 1.20.1** (47.x) и запусти её один раз.
2. Скачай `litrpg-system-1.0.0.jar` из раздела **Releases** этого репозитория.
3. Положи файл в папку `.minecraft/mods` (в TLauncher: кнопка папки → `mods`).
4. Запусти игру.

## Управление
| Клавиша | Действие |
|---|---|
| K | Окно персонажа (распределение очков) |
| M | Карта мира (ПКМ — поставить/убрать метку, колесо — масштаб) |
| N | Мини-карта вкл/выкл |
| Z / X / C / V / B | Навыки 1–5 |

Клавиши меняются в «Настройки → Управление → LitRPG: Система».

## Система
- Опыт за убийства зависит от здоровья и уровня моба. Каждый уровень даёт **3 очка**.
- **Сила** — урон, **Ловкость** — скорость бега и атаки, **Выносливость** — здоровье и броня, **Интеллект** — мана и магический урон.
- Смерть отнимает 10% текущего опыта.
- У всех враждебных мобов есть уровень: чем дальше от точки спавна, тем сильнее. В Изнанке — от 10-го.

## Навыки
| Навык | Уровень | Мана | Описание |
|---|---|---|---|
| Рывок | 1 | 15 | Рывок вперёд |
| Стрела маны | 3 | 20 | Магический снаряд |
| Исцеление | 5 | 30 | Лечение, снимает яд |
| Сокрушающий удар | 8 | 35 | Урон и отбрасывание вокруг |
| Ярость берсерка | 12 | 50 | Сила II, скорость, защита |

## Мобы и боссы
- **Гоблин**, **Гоблин-шаман** (магия, лечит гоблинов) — в обычном мире ночью и в Изнанке.
- **Скелет-страж** — в Изнанке.
- **Король гоблинов** (босс, ур. 15): прыжки с ударом по земле, на 50% HP зовёт свиту.
  Призыв: «Печать Короля гоблинов» (8 ушей гоблина + золотой блок).
- **Лич-архимаг** (босс, ур. 30): залпы магии, телепорты, призыв стражей.
  Призыв: «Филактерия Лича» (8 осколков кости + алмаз), только в Изнанке.

## Изнанка
Вечная ночь, тёмный лес, сильные монстры. Вход и выход — **Ключ Системы**
(аметист сверху, ухо гоблина в центре, 3 золотых слитка).

## Сборка
Мод собирается автоматически через GitHub Actions при каждом пуше; готовый `.jar`
появляется в Releases.
